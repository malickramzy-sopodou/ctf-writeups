# CTF Writeups

Bienvenue sur mon dépôt de writeups de challenges CTF.

Ce repository a pour objectif de documenter mes résolutions, mes réflexions et les techniques que j'apprends au fil de mes exercices en cybersécurité.

## Pourquoi ce dépôt ?

Ce projet me sert à :
- pratiquer et consolider mes compétences en cybersécurité ;
- garder une trace de mes solutions et de mes méthodes ;
- montrer mon évolution dans la résolution de défis ;
- utiliser GitHub comme support de portfolio et de preuve de travail.

## À propos de moi

Je suis étudiant en cybersécurité et je souhaite développer mes compétences à travers la pratique sur des plateformes comme OverTheWire, TryHackMe, HackTheBox, RootMe, PicoCTF et d'autres.

## Structure du dépôt

Les writeups sont organisés par plateforme puis par niveau ou catégorie :

- `OverTheWire/`
  - `Bandit/`
- `TryHackMe/`
- `HackTheBox/`
- `PicoCTF/`
- `RootMe/`
- `CryptoHack/`

## Compétences en développement

À travers ces exercices, je travaille notamment sur :
- Linux et la ligne de commande ;
- scripting Bash / Python ;
- manipulation de fichiers et de flux ;
- bases du réseau ;
- cryptographie et analyse de données ;
- utilisation de Git et GitHub.

## Méthode de travail

Pour chaque challenge, je cherche à comprendre :
1. l'objectif du niveau ;
2. les indices fournis ;
3. les commandes ou outils utiles ;
4. la logique derrière la solution ;
5. ce que j'ai appris à la fin.

## Objectif personnel

Mon but est de progresser régulièrement, de construire un portfolio solide et de montrer que je sais apprendre, analyser et résoudre des problèmes techniques.

## Note

Ce dépôt est en constante évolution. Il reflète mon parcours d'apprentissage en cybersécurité.
